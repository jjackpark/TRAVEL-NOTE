# 먹고 걷고

수원에서 출발하는 40개 지역의 2박 3일 여행 코스입니다.

## 휴대폰에서 보기

웹 주소: https://jjackpark.github.io/TRAVEL-NOTE/

- 안드로이드: Chrome에서 열고 메뉴 → 홈 화면에 추가
- 아이폰: Safari에서 열고 공유 → 홈 화면에 추가

웹 바로가기이며 앱 설치나 오프라인 저장 기능은 없습니다. 수정 후에는 새로고침해 주세요.

## 내용과 사진

- 40개 코스, 120일 일정, 478개 방문 구간
- 실제 식당·카페 295곳: 337개 식사·카페 구간에 연결
- 영업시간, 쉬는 요일, 브레이크타임, 주문 마감, 주소와 출처 표시
- 영업정보 확인일: 기존 1~30번 2026-09-17, 새로 작성한 31~40번 2026-09-19. 공개 운영표 기준이며 임시휴무·가격·주차 등은 방문 전 확인이 필요합니다.
- 40개 대표 사진과 478개 일정 사진(고유 파일 431개). 31~40번은 지역별 일정·매장·숙박 권역·사진을 새로 작성했습니다.
- 식사·카페 335개 구간은 해당 매장 사진. 피쉬스토리와 양평해장국 염치휴게소점 2개 구간은 메뉴 참고 사진임을 표시
- 주변 풍경을 쓰는 구간은 설명에 표시. 출처와 확인 가능한 라이선스는 상세 화면 및 PHOTO-CREDITS.md 참고

사진 출처 표시는 재배포 허가를 의미하지 않습니다. 자유 이용 라이선스가 없는 매장 후기·관광정보 사진의 권리는 원 게시자에게 있습니다.

## 컴퓨터에서 수정하기

최상위 index.html을 열면 dist/index.html로 이동합니다. data/*.json을 수정한 후 `node build.mjs`를 실행합니다. 로컬 미리보기는 `node preview.mjs` 실행 후 http://127.0.0.1:4173 에서 볼 수 있습니다.

GitHub Pages는 main 브랜치의 루트 폴더를 게시합니다. 조사 중간 파일은 research/에 로컬로 보관하며 배포에 포함하지 않습니다.

`node validate-courses.mjs`로 40개 코스의 순서·사진 경로와 31~40번의 지역 주소, 아산 복제 흔적, 식사 7끼, 금~일 영업시간·브레이크타임 충돌을 검사합니다. 이후 `node build.mjs`로 배포 파일을 생성합니다.
