# 먹고 걷고

## 휴대폰에서 사용하기

가장 간단한 방법은 GitHub Pages로 웹사이트를 연 다음 휴대폰 홈 화면에 바로가기를 추가하는 것입니다. 현재 GitHub 업로드와 웹사이트 공개는 별도이며, 아래 설정을 완료해야 웹 주소가 열립니다.

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
3. **main** 브랜치와 **/(root)** 폴더를 선택하고 **Save**를 누릅니다.
4. 배포 완료 후 `https://jjackpark.github.io/TRAVEL-NOTE/`에 접속합니다. 첫 배포는 최대 약 10분 걸릴 수 있습니다.
5. 안드로이드 Chrome에서는 메뉴 → **홈 화면에 추가**, 아이폰 Safari에서는 공유 → **홈 화면에 추가**를 선택합니다. 메뉴 이름은 OS 버전에 따라 조금 다를 수 있습니다.

이 사이트는 웹 바로가기이며 APK나 앱스토어 앱이 아닙니다. 인터넷 없이 쓰는 오프라인 저장 기능은 아직 없습니다. 사진을 포함한 파일은 저장소의 **Code → Download ZIP**으로 받을 수 있지만, 휴대폰에서는 로컬 HTML 실행이 제한되거나 파일 간 연결이 동작하지 않을 수 있어 웹 주소 사용을 권합니다. 컴퓨터에서는 ZIP을 풀고 최상위 `index.html`을 열면 됩니다.

공식 안내: [GitHub Pages 설정](https://docs.github.com/en/pages/quickstart)

## 컴퓨터에서 사용·수정하기

`index.html`을 더블클릭하면 사이트가 열립니다. 외부 라이브러리 없이 로컬 사진과 HTML/CSS/JS로 동작합니다. 원본 참고 자료는 `먹고걷고` 폴더에 보존했습니다.

코스 원본은 `data/*.json`입니다. 코스를 추가하거나 수정한 뒤 이 폴더에서 `node build.mjs`를 실행하면 `dist/index.html`이 다시 만들어집니다. HTML에 내용이 미리 생성되어 JavaScript를 끄더라도 일정과 아코디언 내용을 읽을 수 있습니다.

미리보기: `node preview.mjs` 실행 후 http://127.0.0.1:4173 접속.

개인 로컬용으로 제작했습니다. 사진 출처와 각 장소의 참고 자료는 상세 화면에 표시합니다. 모든 장소의 최신 영업정보나 3개 출처 검증을 완료한 것은 아니며, 미확인 정보를 표시했습니다. 유튜브 API 기반 인기 점수는 미구현입니다. 공개 배포 전 사진 이용 권한 재검토가 필요합니다.

강릉을 포함해 총 11개 지역 코스가 있습니다. 추가 지역은 설악산·속초, 춘천, 단양, 공주·부여, 전주, 군산, 여수, 경주, 통영, 부산입니다. 모두 2박 3일이며, 새 코스는 각각 7끼 식사 시간을 포함합니다. 일부 식당·카페는 현장 선택 구간이고 숙소는 미선정입니다. 이동시간과 방문시각은 계획용 추정치입니다.

지역별 대표 장소 사진과 음식 사진을 추가해 총 30개 로컬 이미지 파일을 사용합니다. 일정 썸네일, 상세 사진과 확대 보기를 지원합니다. 함양집 음식 사진은 지점 미확인 참고 사진임을 표시했습니다. 기존 강릉 코스와 사진은 유지했습니다.

검증: 11개 코스·33일 일정·새 코스별 7끼 구성, 로컬 이미지 파일 존재 및 HTTP 200 응답, JS 문법 검사. 지역·테마 필터, 상세 이동, 사진 확대와 모바일 배치를 브라우저에서 확인했습니다. 320px 목록·상세 화면에서 가로 넘침이 없고, 필터 초기화와 음식 사진 확대가 정상 동작합니다.
